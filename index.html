📱 Tuya Cloud QR Code Linking Guide Tuya requires linking your Smart Life or Tuya Smart mobile app to your Cloud Project via QR code before devices can be fetched by the API.
1
Open Tuya IoT Platform
Go to Cloud → Development and open your project.
2
Generate QR Code
Navigate to Devices → Link Tuya App Account → Add App Account. Tuya will display a QR code.
3
Scan with Mobile App
Open Smart Life or Tuya Smart → Me tab → Tap Scan (⛶) in top-right and confirm.
4
Enter API Keys & Sync
Switch to Developer API Keys, paste your Access ID & Secret, and click Save Keys.
